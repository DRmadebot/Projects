classnotes-ai

Turn lecture PDFs into study notes. Runs on your machine through Ollama.

    Don't have Ollama or the model?

    Linux

    curl -fsSL https://ollama.com/install.sh | sh && ollama pull qwen3:4b

    macOS

    brew install ollama && brew services start ollama && ollama pull qwen3:4b

    Windows (PowerShell, then open a new terminal)

    winget install Ollama.Ollama
    ollama pull qwen3:4b
